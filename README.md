# 🤖 Database Chatbot

The **Database Chatbot** is an intelligent assistant that allows users to **query a Supabase PostgreSQL database using natural language**. It features **role-based access control** (Admin vs Employee) and uses **LangChain's SQL agent** powered by **OpenAI (Groq via GPT-4o)** to translate natural questions into SQL and fetch the results. The frontend is built in Flutter for a smooth, cross-platform user experience.

---

## 🚀 Features

### 🧠 Natural Language to SQL
- Converts user questions into valid SQL queries.
- Executes those queries against a **Supabase PostgreSQL** database.
- Returns both the **query output** and the **generated SQL**.

### 🔐 Role-Based Database Views
- Supports two roles:
  - **Admin**: Full access to all tables.
  - **Employee**: Limited access via views (e.g., `employee_view`).
- Enforced at runtime based on role in the request payload.

### 🔄 Real-Time Response
- Uses FastAPI backend to serve responses via a `/query` endpoint.
- Logs intermediate steps and generated SQL for transparency.

## 📦 Backend Architecture

### 🔧 Dependencies

- `FastAPI`
- `SQLAlchemy`
- `langchain`
- `langchain_openai`
- `pydantic`
- `python-dotenv`

### 🗂️ Role-based Metadata Injection

The system uses **manual metadata injection** to enhance context understanding:
```python
table_metadata = {
    "employee_view": {
        "description": "A view containing employee ID and position information.",
        "columns": {
            "employee_id": "Unique identifier for the employee.",
            "position": "Position of the employee."
        }
    }
}
```

## 🧠 LangChain SQL Agent (GPT-4o)

- Uses LangChain’s `create_sql_agent()` to generate executable SQL queries.
- Based on `ZERO_SHOT_REACT_DESCRIPTION` agent type.
- Handles parsing errors and returns intermediate steps for debugging.

## 🔌 API Endpoint

**POST /query**

### Request:
```json
{
  "query": "How many employees are there?",
  "role": "employee"
}
```
## 📲 Frontend (Flutter)

The Flutter frontend allows users to:
- Enter natural language queries.
- Select their role (admin or employee).
- View the SQL generated by the model.
- See the final result in a readable format.

---
## 🔒 Security

- Role-based filtering at the application level (via `view_support=True`).
- Prevents unauthorized table access (e.g., restricts access to `user_credentials` and `employees` for employees).
- CORS-enabled to support secure communication between frontend and backend
